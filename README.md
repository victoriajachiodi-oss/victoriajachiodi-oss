# Victoria Chiodi

### Desenvolvimento web e prototipagem 3D

Estou desenvolvendo meu portfólio com projetos de interface web e modelagem paramétrica. Gosto de transformar ideias em protótipos e registrar com clareza as tecnologias, decisões e próximos passos de cada projeto. Estou aberta a oportunidades profissionais.

## Projetos em destaque

- **[Lume Eventos](https://github.com/victoriajachiodi-oss/portfolio-projetos/blob/main/docs/lume-eventos.md)** — protótipo de plataforma para convites e controle de entrada em festas. **React, TypeScript, Vite**, qrcode.react e html5-qrcode. A integração com Supabase está planejada.
- **[Suporte para interruptor](https://github.com/victoriajachiodi-oss/portfolio-projetos/blob/main/docs/suporte-interruptor.md)** — modelo CAD paramétrico criado com **JavaScript, Node.js e Manifold-3D**, com exportação STL. Protótipo ainda sem validação física.
- **[Sapatinhas para os pés da mesa](https://github.com/victoriajachiodi-oss/portfolio-projetos/blob/main/docs/pes-de-mesa.md)** — peças paramétricas para impressão 3D, feitas com **JavaScript, Node.js e Manifold-3D**. Encaixe e resistência precisam de validação.

## Tecnologias e ferramentas

**React · TypeScript · JavaScript · Node.js · Vite · Manifold-3D · GitHub · Bambu Studio**
